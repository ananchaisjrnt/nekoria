# NEKORIA — SR-007 AUTHORITATIVE COMBAT AND RETALIATION

Implement WebSocket server-authoritative ATTACK validation, attack timing, HIT/MISS/CRIT, damage, monster HP/death, and player retaliation damage. An attacked monster leaves Roaming, stops, faces/engages the attacker, and never continues random roaming during combat. Client only renders server results. EXP, loot, skills, and Auto Battle are out of scope.

Implemented in the combined SR-006/007/008 delivery requested by the user.
