# NEKORIA — SR-008 EXP, LEVEL UP, AND STATUS POINTS

Award server-calculated EXP on monster death. Keep Base Level, current EXP, next-level requirement, and unused Status Points on authoritative session state. Level-up uses the locked Status Point rule. Display Base Level, HP, EXP, and unused points in debug HUD. Persistence and stat spending UI remain out of scope.

Implemented in the combined SR-006/007/008 delivery requested by the user.
