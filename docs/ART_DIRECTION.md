# NEKORIA — ART & VISUAL DIRECTION

## 1. Core Visual Identity

Nekoria is a Cute Fantasy Cat MMORPG.

The visual identity should feel:

- cute
- adventurous
- colorful
- cozy
- magical
- slightly mysterious

It must NOT look like:

- realistic medieval fantasy
- dark/gritty MMORPG
- generic mobile chibi game
- super-deformed oversized-head characters

The world should look cheerful and inviting,
while still allowing mysterious and darker locations later.

---

# 2. Character Direction

All playable characters are anthropomorphic cats.

Primary character reference:

docs/references/character-class-reference.png

THIS IMAGE IS THE MAIN CHARACTER ART-DIRECTION REFERENCE.

Important characteristics:

- anime-inspired fantasy
- cute cat face
- expressive ears and tail
- balanced stylized proportions
- relatively long arms and legs
- detailed fantasy clothing
- readable weapon silhouettes

Do NOT convert the characters into generic super-chibi proportions.

All classes should share approximately the same:

- body proportions
- face style
- cat anatomy

Class identity comes primarily from:

- clothing
- armor
- weapon
- silhouette
- color language
- VFX

---

# 3. Adventurer

Lv1 characters start as Adventurer.

Adventurer should visually look simpler than Class 2.

Design:

- beginner fantasy clothes
- small backpack/pouch
- simple boots
- basic weapon
- cat tail clearly visible
- lightweight adventurer equipment

The Adventurer should still clearly belong to the same visual universe as the Class 2 reference.

Progression should visually feel like:

Adventurer
↓
experienced Adventurer
↓
Job Change
↓
Swordsman / Archer / Mage / Healer

Do NOT make Adventurer look like a completely different art style.

# 5. World Art Direction

World style:

Stylized 3D fantasy.

Use:

- soft shapes
- slightly exaggerated proportions
- colorful environments
- readable landmarks
- stylized vegetation
- clean silhouettes
- soft lighting
- restrained toon shading

Avoid photorealism.

The environment should look good from the game's elevated 3/4 camera.

Small environmental details must not create excessive visual noise.

---

# 7. Paw Meadow Composition

From the normal gameplay camera the player should see:

foreground:
grass / flowers / small props

midground:
monsters / paths / trees

background:
hills + Giant Tree

The map should NOT feel like a flat rectangular game arena.

Use elevation and terrain composition to make it feel like a world.

However:

avoid terrain that makes navigation frustrating.

# 11. Camera-Aware Art

Always design assets for the actual gameplay camera.

Camera:

elevated 3/4 view
approximately 35–50 degrees downward.

Therefore:

- character silhouette must remain readable
- weapons should remain visible
- monsters need recognizable top/side silhouettes
- loot must be visible on ground
- important props should not disappear behind buildings

Avoid designing assets only for close-up screenshots.

---

# 12. Combat Readability

Combat must remain readable when multiple characters/monsters are nearby.

Important feedback:

Normal Hit:
small impact effect

Critical:
stronger impact
CRIT text

Miss:
MISS text

Target:
clear target indicator

Monster death:
clear animation

Rare drop:
distinct visual beam / particles

Avoid excessive screen-filling effects.

---

# 13. Refine Weapon Glow

Weapon visual effects:

+0–+6:
no glow

+7:
light blue subtle glow + particles

+8:
purple stronger glow

+9:
gold glow

+10:
red strongest glow

Even +10 should preserve weapon readability.

Do not turn the entire character into glowing VFX.

---

# 14. UI THEME

UI should complement the cute fantasy world.

Direction:

Fantasy RPG + clean modern usability.

Use:

- warm parchment / cream surfaces where appropriate
- dark translucent HUD panels
- gold/brass accents
- subtle green accents
- rounded fantasy frames
- paw / tail motifs used sparingly

Avoid:

- sci-fi HUD
- cyberpunk neon
- generic Bootstrap appearance
- excessive ornate medieval frames

---

# 16. Damage Numbers

Normal damage:

simple readable number.

Critical:

larger visual treatment.

Miss:

MISS.

Healing:

clearly distinguishable.

Keep animation short.

Damage numbers should not obscure characters.

---

# 17. Ground Loot

Ground loot is important to Nekoria's visual identity.

Items must physically appear in the world.

Common loot:

small subtle indicator.

Equipment:

more visible.

Rare equipment / Soul:

special beam or particle effect.

Player should feel:

"I want to walk over there and pick that up."

---

# 18. Auto Battle Visual Experience

Watching Auto Battle should be enjoyable.

Animation quality matters.

Desired loop:

cat notices monster
↓
runs toward monster
↓
stops at correct range
↓
attack animation
↓
hit reaction
↓
damage number
↓
monster death
↓
loot scatters
↓
cat runs toward loot
↓
pickup feedback
↓
searches for next target

Avoid robotic instant snapping.

Use:

- acceleration/deceleration
- turn smoothing
- animation blending
- short hit reactions
- satisfying loot feedback

---

For prototype prioritize:

Idle
Run
Basic Attack
Hit Reaction
Death
Pickup

Later:

Sit
Skill Cast
Skill Attack
Emotes
Class-specific animation

Idle animation should contain subtle cat personality.

Examples:

tail movement
ear movement
small breathing motion

Do not overanimate.

---

# 20. Prototype Asset Rule

For early development:

PLACEHOLDERS ARE ACCEPTABLE.

Do not delay gameplay implementation waiting for final 3D models.

However:

placeholder dimensions and camera should approximate final intended proportions.

Architecture must allow assets to be replaced later without rewriting gameplay logic.

Separate:

gameplay entity

from:

rendered model / animation.

---

# 21. SOURCE OF TRUTH

When implementing visuals:

1. Reference images in `docs/references/`
2. This ART_DIRECTION.md
3. GAME_DESIGN.md

take precedence over generic assumptions about MMORPG visual style.

If final art is unavailable:

use a placeholder matching the silhouette and scale.

Do NOT invent a completely different visual identity.
